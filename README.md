# 🛠 Getting Started

## ⚙️ Prerequisites

| Tool             | Version |
| ---------------- | ------- |
| Node.js          | >= 22   |
| React Native CLI | Latest  |
| Android Studio   | Latest  |
| JDK              | 17      |

---

### Installation

```bash
git clone https://github.com/night-fury-rider/react-native-template.git
cd react-native-template
npm install
```

### Run

```bash
npm run android
```

## Scripts

```bash
# Enter in Sandbox mode
npm run mode:sandbox
```

```bash
# Exit the Sandbox mode
npm run mode:prod
```

```bash
# Export source files
npm run export-src
```
